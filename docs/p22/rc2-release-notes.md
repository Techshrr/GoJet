## 未验证及后续要求

整机重启、正式域名证书续期、新主机外部服务凭据、实际邮件投递及支付尚未在本轮完成验证。没有部署生产站点。

业务版本必须做到：完成一次性的服务器部署准备后，访问安装页面填写站点、数据库、邮件、风控及初始管理员信息；后台自动完成校验、初始化、迁移、服务启动和健康检查。页面必须显示真实进度、可理解的失败原因，并支持刷新后继续查询及安全恢复。正常安装不得依赖用户逐段执行 SQL、复制升级脚本、手工审批内部状态文件或反复提交终端输出。

安装器须保留受限后台执行权限、凭据保护、幂等与并发锁、失败恢复及安装完成后关闭入口等保护。自动化不能通过给 Web 进程任意 root 权限实现。此要求是后续版本验收条件，当前包尚未完成该体验改造。
