Workspace API keys are released under the signed P17 `CAP-API-KEYS` authority. The raw secret is generated by the server, returned once, and is not recoverable later.

## Routes

```http
GET /api/workspaces/{workspaceId}/api-keys
POST /api/workspaces/{workspaceId}/api-keys
POST /api/workspaces/{workspaceId}/api-keys/{keyId}/rotate
POST /api/workspaces/{workspaceId}/api-keys/{keyId}/revoke
```

## Security contract

Creation, rotation, revocation, expiry, scope, rate enforcement, tenant authorization, and audit are server-authoritative. Documentation examples must use placeholders and must never include a raw API key.

```text
Authorization: Bearer <API_KEY_RETURNED_ONCE>
Workspace: WORKSPACE_ID
```
