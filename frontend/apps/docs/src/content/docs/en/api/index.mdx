The P18 API reference publishes only resources whose owning capability has signed implementation evidence in the current repository.

## Released in this reference

- [Workspace API keys](/docs/en/api/api-keys)
- [Generic outbound webhooks](/docs/en/api/webhooks)

## Not released

Other API resources are not promoted into this P18 API reference until their owning capability has signed evidence. A specification entry by itself is not release authority and does not create a documentation route.

Examples use placeholders such as `WORKSPACE_ID`, `KEY_ID`, and `WEBHOOK_ID`. Raw credentials are never documentation fixtures.
