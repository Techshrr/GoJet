## Independent authorities

- Workspace and administrator permissions are checked by the server on every protected request.
- Destination and domain risk remain independent safety axes.
- Mandatory ClamAV scanning remains the file malware authority.
- Payment callbacks and generic outbound webhooks are different trust boundaries.
- High-risk administrator mutations remain auditable without recording raw secrets.
