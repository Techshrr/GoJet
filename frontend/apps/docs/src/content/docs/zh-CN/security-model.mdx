## 相互独立的权限与安全轴

- Workspace 与管理员权限在每个受保护请求上由服务端重新检查。
- 目标风险与域名风险继续作为彼此独立的安全轴。
- 强制 ClamAV 扫描仍是文件恶意软件判定权限。
- 支付回调与通用出站 Webhook 属于不同的信任边界。
- 高风险管理员变更必须可审计，同时不得记录原始密钥。
