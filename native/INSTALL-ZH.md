# Linketic 原生安装包

无需 Docker。使用 systemd 启动程序，自带所需运行时、MySQL、Redis 和文件扫描服务。程序在独立文件系统中运行；数据保存于 `/var/lib/linketic-native`，不会使用面板上其他网站的数据库。

## 首次安装

1. 将域名解析到服务器，在面板创建站点并配置 HTTPS。以下反向代理步骤适用于运行在宿主机的 Nginx（如宝塔）；1Panel 的容器化 OpenResty 网络尚未实测，不能直接把其容器内的 127.0.0.1 当作宿主机。
2. 解压本安装包。在面板终端进入解压目录，仅运行一次：

   ```sh
   python3 install.py --site-url https://www.linketic.com
   ```

3. 将该站点反向代理到 `http://127.0.0.1:18080`。记录初始化程序显示的安装访问码。
4. 访问域名，输入访问码，在网页填写管理员、SMTP、Google Web Risk 和 Turnstile。点击安装后等待完成，无需再执行数据库或审批命令。

数据库账户和密码由程序自动生成，不需要手工填入。首次下载病毒库可能需要几分钟，网页显示进度。安装失败时保留数据和错误状态，不会把失败显示为成功。

## 环境和运行

- Linux x86_64，systemd，Python 3.11 或更新版本（含最新安全补丁），至少 6 GiB 可用空间。
- 当前验收环境见发布验收记录。其他发行版不能视为已验证支持。
- 仅本机监听的端口：18080、33306、36379、8080、8081、9089、9170、9443。端口冲突会在安装前停止。
- 服务名 `linketic.service`；可使用系统或面板服务管理功能查看状态。
- HTTPS 由已有网站面板管理，独立运行时不覆盖宿主机 Nginx、PHP、MySQL 配置。
- 程序不会自动迁移现有 Docker 数据。本包用于全新原生部署；已有站点请使用对应升级包，保留数据目录。
