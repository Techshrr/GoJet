# Linketic 面板网页安装版

本目录是新安装方式的源代码，必须通过 P23 完整安装验收后才能制作可交付包。旧 Native RC2 ZIP 不是网站目录安装包。

## 安装入口

1. 在宝塔的 Docker 编排中导入交付包里的 `docker-compose.yml`，设置站点域名和独立安装访问码，点击部署。
2. 在宝塔添加反向代理网站：`www.linketic.com` → `http://127.0.0.1:18080`，开启 HTTPS。反代保留原 Host，并设置 X-Real-IP 为来访地址；不要缓存安装页、API 或后台。
3. 打开 `https://www.linketic.com`，输入安装访问码，填写管理员、SMTP、Turnstile 和 Google Web Risk 密钥，然后点击“检查并安装”。

程序自带独立数据库、Redis、病毒扫描、Go 后台服务及 Web Risk 接入。无需在宿主机另建数据库、运行 PHP 命令或提交服务器审批文件。首次部署会自动下载并构建应用，第一次启动会下载病毒库，请在面板查看构建进度。

`linketic.com` 可在面板另设 HTTPS 301 跳转到 `https://www.linketic.com`，证书应覆盖两个域名。

## 环境与保留数据

- Linux x86_64，Docker Engine 和 Compose；建议至少 4 GB 可用内存、10 GB 可用磁盘，构建时可能需要额外内存。
- 能访问 GitHub、Docker Hub、Ubuntu 软件仓库、ClamAV 病毒库、Google 和 Cloudflare API。
- 本版默认适配宿主机 Nginx 的宝塔反代。容器化 OpenResty（例如 1Panel）的网络接入需另行验证，不能直接套用宿主机回环地址。
- 只向宿主机回环地址发布 18080；数据库、Redis、安装工作进程和风控端口不发布。
- 四个命名数据卷保存应用私有配置、数据库、Redis 和病毒库。停止或重新创建容器保留数据；**删除数据卷会删除站点数据**。
- 安装成功后所有安装写接口返回 410，管理员初始明文密码从活动安装请求中删除。安装器不能被用于重新覆盖已安装站点。
- 安装中断可在页面重试。只有本次安装创建、尚未开放业务的数据库可以恢复；迁移中断时先保留 SQL 备份和失败日志，再重新初始化。已完成数据初始化的重试不会重复创建管理员。

## 验证边界

自动测试使用真实 MySQL、Redis、ClamAV、Go 二进制、Nginx 和浏览器；SMTP、Google、Cloudflare 使用独立的 CI 协议测试服务。安装到自己的服务器时仍会使用所填写的真实凭据进行在线验证。不得将 CI 协议测试写成用户外部账户已经验证成功。

本版是新安装容器版本。旧 systemd 原生部署迁移到容器、在线版本升级和宝塔 UI 内导入操作不能仅凭容器测试宣称已验收。
