本版调整注册、登录与密码找回流程，并提供容器安装包和不依赖 Docker 的 systemd 原生安装包。

- 邮箱验证、邮件登录和密码重置改为六位数字验证码，支持粘贴、自动填充、过期提示、重发与倒计时。验证码与邮箱、用途绑定，限制尝试次数并保持一次性使用。
- 注册验证、密码登录、邮件登录、密码重置成功后建立会话并进入客户中心；刷新保留登录状态，退出和密码重置撤销对应旧会话。
- 密码找回在同一页面完成发送邮件、填写验证码及设置新密码。未验证账户可以重发验证邮件。
- 统一官网、认证、客户中心与后台的排版、导航、表单及移动布局。后台用户管理提供表格、筛选和详情；未配置的快捷登录方式不显示。
- OAuth 凭据可在后台配置，保存时要求近期双重验证；秘密值不回显。Google One Tap 仍需有效 Google 登录配置。
- 首次访问域名进入安装向导，数据库凭据自动生成。安装访问验证、依赖检查及失败恢复保留，不需要手动修改网页字段或数据库。
- 已有容器部署保留原四个数据卷升级；仅未自定义的旧版认证邮件模板更新为新的数字验证码样式。

每个发布包包含构建来源、文件校验和及验收摘要。验收使用真实数据库、邮件工作进程和浏览器，外部 SMTP、Web Risk、Turnstile 使用隔离协议测试服务。真实收件箱投递、真实 OAuth 服务商登录、宝塔镜像导入界面与 1Panel 容器网络不属于这些测试的证明范围。

原生包用于全新 Linux x86_64 / systemd 部署，验收目标为 Ubuntu 24.04。宿主机只需一次初始化以启动安装入口，业务配置在网页完成；本包不迁移旧 systemd 或 Docker 数据。已有站点请按对应升级说明操作，保留数据。
