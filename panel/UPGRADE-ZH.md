# 已安装站点更新（panel.1 / panel.2 / panel.3 → panel.4）

本次将邮箱验证、邮箱登录和密码重置统一为六位数字验证码；注册验证及重置完成后自动登录并进入客户中心。补齐登录状态、同页密码找回和后台用户管理界面。无需重新安装、重建账户或修改数据库。

1. 在面板文件管理中上传本 ZIP，解压到网站目录以外。通过 Docker 镜像管理导入 `linketic-image.tar`。
2. 编辑**现有 Linketic 编排项目**，仅将应用镜像改为 `linketic-panel:10.0.0-rc.2-panel.4`。保留原项目名称、四个数据卷、SITE_URL、INSTALL_ACCESS_CODE 和端口配置。不要创建另一个项目，也不要删除原容器的数据卷。
3. 保存并重新部署该项目，待容器正常运行后强制刷新网页。更新期间会短暂中断服务。无需重新填写安装向导；若出现首次安装页，先停止操作并核对是否误用了新项目或新数据卷。

更新前保留现有数据备份和旧镜像。本版本不新增数据库迁移、不轮换密钥；仅将未自定义的默认验证邮件模板升级为新样式，保留旧模板版本。回退到旧版本后应重新申请验证码；如需回退，可在同一项目恢复原镜像标签并重新部署，保留原四个数据卷。

## 恢复未验证账户

打开 `https://你的域名/verify-email`，填写原注册邮箱，点击发送验证码；收到邮件后在同一页填写六位数字。验证成功后自动进入客户中心。也可在登录提示需要验证邮箱时直接点击重发。无需删除账户。

重发间隔为 60 秒；重新发送后请使用最新验证码。邮件由原有 SMTP 服务发送，投递失败详情可在后台 Mail 查看。CI 验证的是完整 SMTP 协议投递和验证码使用流程，不代表每一家真实收件服务均已验收。

## 配置第三方登录

后台侧栏 **Sign-in providers**，或 **Platform → Configure customer sign-in providers**，进入 `/admin/platform/oauth`。选择服务商，填写其真实 Client ID、Client secret 和所需参数，启用并保存。

页面显示当前站点回调地址。先在对应服务商开发者后台登记同一地址。密钥保存后不会回显；修改要求管理员近期完成双重验证，页面会提供设置入口。未配置或未启用的服务商不再显示在客户登录页。

Google One Tap 是 Google 登录的附加显示方式，不能代替 OAuth 凭据配置。包内不包含任何服务商的客户凭据。
